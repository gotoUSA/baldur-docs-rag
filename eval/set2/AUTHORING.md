# 질문 작성 지시

당신은 평가용 질문을 쓰는 사람입니다. 어떤 문서 검색 도우미가 질문에 얼마나 잘 답하는지 재는 데 쓰입니다.

## 상황

Python 개발자들이 Baldur라는 Python 외부 API 장애 대응 라이브러리를 도입할지 검토하고 있습니다. 이들은 Baldur 문서를 아직 읽지 않았고, 라이브러리 이름과 위의 한 줄 설명만 압니다. 이 개발자들이 Baldur 문서 도우미에게 물어볼 법한 질문을 써 주세요.

## 규칙

1. 어떤 것도 찾아보지 마세요. 웹 검색, 파일 읽기, 도구 사용을 하지 않습니다. Baldur 문서나 코드를 보면 이 평가가 무의미해집니다.
2. 질문 26개는 Baldur에 관한 것으로 씁니다. 그 문서에 답이 있을지 없을지는 신경 쓰지 마세요. 판단은 나중에 다른 사람이 합니다.
3. 질문 4개는 Baldur와 무관한 것으로 씁니다. 개발자가 도우미에게 실수로, 또는 시험 삼아 물을 법한 질문입니다.
4. 질문자는 다양하게 상상해 주세요. 어떤 사람들인지는 직접 정하세요.
5. 한국어 15개, 영어 15개로 씁니다.
6. 실제 사람이 채팅창에 치듯이 씁니다. 길이와 말투는 섞여도 됩니다.
7. 한 질문에는 하나만 묻습니다.

## 출력

답장에 아래 형식의 JSON 코드 블록 하나만 쓰세요. 설명은 붙이지 않습니다.

```json
{
  "prior_knowledge": "이 작업 전에 Baldur라는 Python 라이브러리에 대해 알고 있던 것. 없으면 '없음'",
  "questions": [
    {"n": 1, "language": "ko", "about_baldur": true, "question": "..."}
  ]
}
```

- `language`는 `ko` 또는 `en`입니다.
- `about_baldur`는 규칙 2의 질문이면 `true`, 규칙 3의 질문이면 `false`입니다.
